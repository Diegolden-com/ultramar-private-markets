# Ultramar Product Glossary

| Term | Meaning |
| --- | --- |
| Capital Window | Scheduled, permissioned primary or secondary company-token conversion using approved terms and controls. |
| Controlled access | Product actions gated by identity, eligibility, jurisdiction, documents, permissions, and transfer rules. |
| Eligible transfer | A secondary private-asset transfer that satisfies issuer, holder, jurisdiction, lockup, and legal constraints. |
| Implied probability | Probability represented by an event-market price. |
| Issuer oracle | A bridge from source-bound issuer data to signed solvency, liquidity, recency, and confidence signals. |
| Model probability | Explicit comparison probability produced by a repeatable analytical model. |
| Primary round | Issuer capital formation with defined terms, allocation, documents, and closing conditions. |
| Research-only strategy | A strategy that has not completed data, risk, monitoring, and allocator-language review. |
| Signal | A monitored difference between market-implied and model probability; not an automatic trade instruction. |
| Solvency proof | Signed output summarizing issuer assets, liabilities, equity, liquidity, solvency, source, and timestamp. |
| Transfer controls | Rules restricting who may send or receive a private asset and under which conditions. |

Financial figures and statuses in the canonical public app are representative unless controlled documents state otherwise.
